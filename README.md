# FS25_AgriLifeManager

**AgriLife Manager** est un mod PC pour Farming Simulator 25 visant une gestion agricole beaucoup plus profonde : banque, conseiller, carrière, personnel, examens, société, assurances, atelier, contrats et systèmes administratifs liés à la vie de l'exploitation.

## État du projet

- Développement actif — builds TEST
- Version de travail actuelle : **0.6.4.23 TEST**
- Plateforme cible : **PC**
- Auteur : **Chez_Squall**
- Dépôt de développement : **privé tant que le mod n'est pas prêt pour une publication stable**

## Principes du projet

- Le cœur d'AgriLife Manager doit fonctionner de façon autonome.
- Les compatibilités avec Courseplay, AutoDrive, Soil Fertilizer et d'autres mods doivent rester optionnelles et ne pas devenir des dépendances obligatoires.
- Le niveau de difficulté est permanent par sauvegarde.
- Les nouvelles carrières utilisent le capital de départ AgriLife et neutralisent le crédit de départ FS25.
- Les sauvegardes existantes conservent leur argent, leurs biens et leur dette FS25 héritée.
- La Banque et, plus tard, le module Huissier sont des systèmes majeurs et doivent être particulièrement détaillés.
- Toute fonctionnalité importante doit être documentée dans le tutoriel initial et dans Échap → Assistance.
