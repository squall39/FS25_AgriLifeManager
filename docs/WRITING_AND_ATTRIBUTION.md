# Writing and attribution rules

These rules apply to all AgriLifeManager project output: commits, pull requests, releases, README files, documentation, code comments, in-game text, ledger entries, changelogs and packaging notes.

## Writing voice

- Use a plain, human voice.
- Never use the em dash character.
- Use a normal hyphen, a comma, parentheses, a colon or a separate sentence instead.
- Check text before publishing or packaging.

## Attribution

- Do not add `Generated with...`, `Co-Authored-By:`, AI vendor links or AI attribution anywhere in public project material.
- Do not mention AI assistants, model names or vendors in commits, pull requests, release notes, README files, documentation, code comments or in-game text.
- The mod remains attributed to its human author.
- Public author identity for AgriLifeManager remains `Chez_Squall` unless the author explicitly changes it.

## Pre-ship check

Before any commit, release, build or documentation update:

1. Scan changed text for the em dash character.
2. Scan for AI attribution or vendor references.
3. Confirm the author attribution remains `Chez_Squall` where an author field is required.
4. Fix any violation before shipping.
