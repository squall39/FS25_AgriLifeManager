# Glossaire AgriLife Manager

Ce glossaire stabilise les termes fonctionnels utilisés dans l'interface, les traductions et la documentation.

| Concept | Terme français de référence | Sens AgriLife |
|---|---|---|
| Farm | Exploitation | Entité agricole FS25 possédant ses propres données AgriLife. |
| Manager | Dirigeant | Personne responsable de l'exploitation. |
| Reputation | Réputation | Note durable influencée par la gestion et les résultats. |
| Career | Carrière | Progression professionnelle du joueur. |
| Qualification | Qualification | Autorisation spécialisée obtenue par progression ou examen. |
| Permit | Permis | Autorisation de conduite agricole gérée par AgriLife. |
| Contract | Contrat | Engagement commercial avec volume, prix, délai et conséquences. |
| Buyer | Acheteur | Partenaire commercial recevant un produit ou une production. |
| Cooperative | Coopérative | Acheteur ou partenaire agricole avec relation durable. |
| Workshop | Atelier | Système de diagnostic, entretien, réparation et immobilisation. |
| Dealer | Concessionnaire | Prestataire technique et commercial externe. |
| Claim | Sinistre | Dossier assurance ouvert à la suite d'un dommage déclaré. |
| Accident statement | Constat | Dossier décrivant les circonstances et la responsabilité d'un accident. |
| Liability | Responsabilité | Part de responsabilité retenue pour un accident. |
| Bonus-malus | Bonus-malus | Coefficient durable influençant certaines primes d'assurance. |
| Technical inspection | Contrôle technique | Vérification périodique de conformité et de sécurité. |
| Service | Révision | Entretien périodique obligatoire adapté au matériel. |
| Breakdown | Panne | Défaillance technique avec conséquence fonctionnelle. |
| Part | Pièce | Composant de remplacement commandé ou stocké. |
| Used | Occasion | Matériel ou pièce déjà utilisé avec historique et état propres. |
| Refurbished | Reconditionné | Pièce restaurée avec fiabilité et garantie spécifiques. |
| Compliance | Conformité | État du respect des obligations administratives applicables. |
| Enforcement | Contentieux | Escalade après dette, sanction ou obligation non régularisée. |
| Save isolation | Isolation de carrière | Garantie qu'une carrière ne récupère pas les données d'une autre. |

Les traductions peuvent adapter la formulation à la langue cible, mais doivent conserver le même sens fonctionnel.
